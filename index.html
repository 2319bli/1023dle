HOW TO PLAY

Find the right colours.

Each lamp has a current colour and a GOAL colour. Match all ten to reach 1023. Each lamp is a binary bit: match = 1, mismatch = 0. Lamps A–J are worth 512, 256, 128, 64, 32, 16, 8, 4, 2, and 1. All matched gives 1111111111₂ = 1023. Symbols distinguish colours too: Amber ●, Cyan ▲, Violet ◆.

Cycle ↻: advance the listed lamps through Amber → Cyan → Violet → Amber. Reverse ↺: step through those colours backwards.

Swap ⇄: exchange two lamps’ current colours. Rotate ⟳: pass colours along the three listed lamps, with the last returning to the first. Goal colours and values stay in place.

Every action costs one move, even if the colours stay unchanged. Order matters. A cycle repeated three times cancels itself; a swap repeated twice cancels itself.

Daily: a shared colour puzzle at 00:00 UTC. No hints. Practice: unlimited random puzzles with hints. Endless: solve each circuit in the exact minimum + 2 moves or fewer, or your run ends. No hints.

Hover or focus a control to trace its lamps. Use keys 1–9, 0, Q, W, E, R, or tap the controls. Each mode saves separately. Shortest sequences are calculated using all four operation types.
